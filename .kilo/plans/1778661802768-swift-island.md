# Plan: Tenant Archiving with Date In/Date Out Period Tracking

## Summary
Implement tenant archiving that tracks rental periods (date in/date out) so room units can have different tenants over time. Archived tenants should display in a dedicated section below active tenants on the tenants page.

## Current State Analysis

### Existing Implementation
1. **Tenant Archive Modal** (`archiveTenantModal` in index.html:1140-1189)
   - Collects: tenant end date, final bill, deposit returned, electricity/water readings
   - Missing: explicit "date in" field (currently uses `tenant.since` but not editable in archive)

2. **Archive Functions** (script.js:7060-7134)
   - `showArchiveModal()` - displays modal with tenant info
   - `confirmArchiveTenant()` - sets `archived=true`, `tenantEnd` date
   - Archived tenants get `archived: true` flag

3. **Tenant Rendering** (script.js:4209-4362)
   - Active tenants filtered by `!tenant.archived`
   - Archived tenants section already exists (lines 4316-4356)
   - Shows: name, unit, phone, email, moved in/out dates, deposit returned

### Issues to Address
1. The archive modal does not clearly show/edit "date in" (move-in date)
2. Need to ensure `tenant.since` is properly used as "date in" for archived tenants
3. Need to verify archived section displays correctly with proper date formatting

## Implementation Plan

### 1. Update Archive Modal HTML (index.html)
- Add editable "Date Tenant Moved In" field to the archive modal
- This ensures both date in and date out are visible during archiving

### 2. Update Archive Logic (script.js)
- Modify `showArchiveModal()` to populate date in field
- Modify `confirmArchiveTenant()` to ensure `tenant.since` is preserved as date in
- Add `tenantDateIn` field for clarity if needed

### 3. Enhance Archived Tenant Display (script.js renderTenants)
- Ensure archived section shows both:
  - "Moved In:" (from `tenant.since`)

- Already partially implemented at script.js:4342-4343

### 4. Verify Tenant Timeline Support
- Ensure multiple tenants can occupy the same unit over time
- The duplicate check already excludes archived tenants (line 3636)
- Verify new tenants can be added to previously occupied units
